# SatQuery AI

## Agentic Vision-Language Assistant for Remote Sensing

SatQuery AI is an AI-powered assistant for analyzing satellite imagery using natural-language queries.

### Main Features

- Single-image Visual Question Answering
- Satellite image captioning
- Image grounding
- Bi-temporal change detection
- Optical + SAR analysis
- Agentic task selection
- Spatial evidence visualization
- Confidence estimation
- Execution trace
- PDF report generation
